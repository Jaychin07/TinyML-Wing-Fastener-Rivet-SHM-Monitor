APU Final Year Project · Structural Health Monitoring

TinyML Anomaly Detection for Aircraft Fasteners and Rivets

A real-time SHM prototype that detects early mechanical degradation in aerospace joints. Inference runs on the microcontroller itself, with no cloud compute needed to classify.

NORMAL LOOSE RUSTED
System architecture

Input, process, output

A vibration motor sends a repeatable wave through a mock wing panel. An accelerometer records how the joint responds, and the ESP32 classifies that response.

Input: excitation and sensing

  • 5 V PWM vibration motor, toggled by a debounced push button
  • Waves travel through a 3D-printed cantilevered wing panel
  • MPU6050 captures the vibration response along the acoustic path

Process: edge AI

  • ESP32 acquires time-series acceleration windows
  • FFT spectral analysis extracts frequency features
  • Quantized Edge Impulse model classifies locally

Output: visualization

  • SSD1306 OLED shows class, motor state and live Z-axis value
  • JSON packets stream over Wi-Fi and MQTT
  • Web dashboard renders telemetry remotely

Mechanical CAD · SolidWorks

Cantilevered wing test panel

A right-wing specimen, 150 × 80 × 5 mm, printed in PLA at 100% infill and mounted to a 10 mm base in a U-channel profile. The motor, the five M4 rivet holes and the sensor all sit on one centerline, 23 mm from the trailing edge.

Top view, drawn to scale at 4 px per mm. Rivet 3 at 75 mm is the universal test bed for every fastener condition.

Vibration data collection and model training

Controlled vibration sweeps at Rivet 3 across three fastener conditions:

NORMALFully tightened M4 socket head bolt with metal washer.
LOOSEPartially backed-off, untorqued M4 bolt that introduces mechanical play.
RUSTEDCorroded fastener, or rubber/nylon damping washer, simulating joint stiffness loss.
  • Stream labelled 3-axis samples into Edge Impulse at 100 Hz in 1000–2000 ms windows.
  • Configure a Spectral Analysis (FFT) block and neural network classifier, check the confusion matrix, and export the quantized C++ Arduino library.
